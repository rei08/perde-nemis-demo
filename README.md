# Perde Nemis — website demo

A clickable demo of the Perde Nemis curtains website. Every order, customer, price and stock figure in it is a sample.

- `index.html` — the public pages only (home, fabrics, rails, configurator, booking, tracking).
- `full.html` — the same with the staff side (order board, rail stock, calendar) and its sample prices.

Both files are generated from the demo sources by `demo/tools/standalone.py noindex`; do not edit them by hand.
